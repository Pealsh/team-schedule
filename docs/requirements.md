# チーム予定共有ツール 要件定義

## 1. 目的
チームメンバーの予定を1か所に集め、**全員が空いている時間をひと目で見つける**。
予定の入力は画面からでも、AI（MCP / REST API）からでもできる。
使えるのは、許可リストに載った Google アカウント（Gmail）だけ。

## 2. 構成

| 層 | 技術 | 備考 |
|---|---|---|
| 画面 | HTML + CSS + 素の JS（ビルド無し） | GitHub Pages で配信 |
| ログイン | Firebase Authentication（Google） | 無料枠。SDK は gstatic の CDN から読む |
| データ | Firebase Cloud Firestore（REST API） | 無料枠（Spark）。停止なし |
| AI 連携 / REST API | Cloudflare Worker（`worker/`） | 無料枠（1 日 10 万リクエスト）。MCP は Streamable HTTP |

ランタイムの依存は Firebase Auth SDK だけ。データの読み書きは `fetch` で Firestore REST を直接叩く。
Worker は依存ゼロ（MCP の JSON-RPC も手書き）。

## 3. 機能要件

### 3.1 メンバー
- F-01 メンバーを追加できる（名前のみ入力。色はパレットから自動割当、変更可）
- F-02 メンバーを削除できる（その人の予定も削除）
- F-03 凡例のメンバーをタップすると表示 ON/OFF（空き判定の対象からも外れる）

### 3.2 予定
- F-10 予定を追加できる：メンバー・タイトル・日付・開始・終了（15分刻み）
- F-11 予定をタップすると詳細表示、削除できる
- F-12 日をまたぐ予定は、表示中の日の範囲だけ切り取って表示する

### 3.3 1日タイムライン（メイン画面）
- F-20 1日ずつ縦に表示。0:00〜24:00、1時間ごとに目盛り
- F-21 メンバーごとに縦のレーン（列）を持ち、予定がある時間を**その人の色の縦線（バー）**で表示
- F-22 **表示中メンバー全員が空いている時間帯**を背景色で強調
- F-23 画面上部に空き時間の一覧（例：`9:00–10:30 / 13:00–15:00`）を表示
- F-24 前日 / 今日 / 翌日ボタン、日付選択
- F-25 今日を表示中は現在時刻に線を引き、初回はその付近までスクロール
- F-27 「空き」で、表示中メンバー全員が空いている時間を今日から 14 日分一覧にする。日付順／長い順、時間帯・最小の長さで絞り込み。タップでその時間に予定追加
- F-26 「日 ｜ 月 ｜ 空き」で月表示（日曜始まりのカレンダー）に切り替えられる。各日に予定を最大 3 件（色・開始時刻・タイトル）、残りは「他 n 件」。スマホ幅では色の点だけ。日付をタップでその日の 1 日表示へ

### 3.4 API / AI 連携
- F-30 REST API（Worker の `/api/*`、接続トークンで認証）で予定・メンバーの CRUD と空き時間検索ができる
- F-31 MCP ツールを提供する（Worker の `/mcp/<接続トークン>`。claude.ai・スマホ・Claude Code から URL だけで接続）
  - `list_members` / `add_member`
  - `list_events`（日付範囲）/ `add_event` / `delete_event`
  - `find_free_slots`（日付・メンバー・最小分数 → 全員の空き時間）
- F-32 メンバーは名前で指定できる（AI が ID を知らなくてよい）

### 3.5 ログインと接続
- F-40 Google アカウントでログイン / ログアウトできる。未ログインならログイン画面だけを出す
- F-41 許可リスト外のアカウントには「許可されていません」と出す
- F-42 オーナーは画面で許可リスト（Gmail）を追加・削除できる。オーナー自身は外せない
- F-43 「AI・API と接続」で接続 URL（MCP / REST 用のトークン）を発行できる。URL は発行時に 1 回だけ表示する
- F-44 発行済みの接続 URL を一覧から無効化できる。許可リストから外れた人の URL もすぐ使えなくなる
- F-46 ログインした人は自動でメンバーになる（名前は Google の表示名、色は自動）。自分の名前はアイコンメニューから、オーナーは全員の名前を「メンバー」画面から変えられる
- F-45 オーナーは招待リンク（7 日間有効・何人でも）を発行・無効化できる。開いて Google でログインした人は自動で許可リストに入る

## 4. 非機能要件
- N-01 シンプルで軽い：最初に読み込む自前の JS+CSS 合計 45KB 以下（外部 SDK は数えない）、ビルド不要
- N-02 PC とスマホ両対応。幅 360px でも横スクロール無し
- N-03 ライト／ダーク切替ボタン（初期値は OS 設定、選んだ方を記憶）
- N-04 アクセス制限：`teams/{チームキー}.allowed` に載った Google アカウント（メール確認済み）だけが読み書きできる
  （セキュリティルールで確認。Worker はサービスアカウントで入り、接続トークンの発行者が許可リストに居るかを毎回確認する）
- N-07 接続トークンはハッシュ（SHA-256）だけを保存する。漏れたら画面から無効化する
- N-05 時刻は Firestore の timestamp で保存し、表示はブラウザのタイムゾーン
- N-06 他の人の変更は、画面フォーカス時と 60 秒ごとに再読み込みで反映

## 5. データモデル（Firestore）

```
teams/{チームキー}
  name        string
  owner       string    オーナーの Gmail（コンソールで設定）
  allowed     string[]  読み書きを許可する Gmail（owner を含む）
  members/{自動ID}
    name        string  1〜30文字、チーム内で重複不可（アプリ側で確認）
    email       string  ログインで自動作成されたメンバーだけ。本人のメールのみ・変更不可
    color       string  #RRGGBB
    created_at  timestamp
  events/{自動ID}
    member_id   string  members の ID（メンバー削除時はアプリ側で一緒に消す）
    title       string  1〜80文字
    starts_at   timestamp
    ends_at     timestamp  starts_at より後
    created_at  timestamp

tokens/{SHA-256(接続トークン)}      MCP / REST 用の接続トークン
  team        string
  email       string     発行した人の Gmail
  label       string     1〜40文字
  created_at  timestamp
```

予定の日付検索は `starts_at` だけで行う（複合インデックス不要にするため）。7日を超える予定は範囲検索から漏れる。

## 6. 範囲外（今回やらない）
- MCP の OAuth 接続、接続トークンの有効期限・権限の細分化
- 1 人が複数のチームに入ること
- 繰り返し予定、通知、Google カレンダー連携
- 週表示

## 7. 受け入れ条件
- 空き時間計算のユニットテストが通る（`npm test`）
- 画面から メンバー追加 → 予定追加 → 空き時間が強調される
- Claude から「明日 A さんと B さんが1時間空いてる時間は？」で `find_free_slots` が答える
- 許可リスト外のアカウントでは読み書きできない（`npm run test:rules`）
- 接続 URL を無効化すると、その URL からの MCP / REST が 401 になる
